# Churn Analysis

This project analyzes customer churn data to identify patterns and factors that contribute to customers leaving a service. It uses Python and pandas to explore the dataset, build queries, and support data-driven insights.

## Project purpose

The goal is to study churn-related behavior by examining customer attributes such as senior citizenship, dependents, gender, and other available features in the dataset. The project is designed for exploratory analysis and can be extended with additional modeling or reporting.

## Repository structure

- `data/` – contains the churn dataset used in the analysis
- `notebook/` – Jupyter notebook with the analysis workflow
- `src/` – Python scripts for loading and querying the dataset

## Tools used

- Python
- pandas
- NumPy
- Jupyter Notebook

## Example workflow

1. Load the dataset from `data/churn_dataset.csv`
2. Explore customer attributes and churn patterns
3. Run custom queries to answer business questions
4. Use the notebook or scripts for further analysis

## Notes

This is a lightweight data analysis project focused on understanding churn trends and preparing the data for deeper investigation or predictive modeling.
